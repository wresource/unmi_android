# Changelog

## v1.0.5

<en-US>
Added guest mode, 30-day login cache, and logout option. Built-in review account for Google Play. Fixed startup flicker and database migration crashes. Improved Settings alignment and i18n coverage.
</en-US>

<zh-CN>

## v1.0.2

### 中文

全新重构：基于 Jetpack Compose + Material Design 3 重写 UI，支持中英文切换。新增 ICANN RDAP/WHOIS 一键识别、nazhumi.com 价格查询、域名价值评估算法。密码即账户的多账户系统，AES-256-GCM 加密存储。Release 包体仅 6.4MB。

### English

Full rewrite with Jetpack Compose + Material Design 3 and Chinese/English i18n. Added ICANN RDAP/WHOIS auto-identify, nazhumi.com pricing API, and domain valuation algorithm. Password-as-account multi-user system with AES-256-GCM encrypted storage. Release APK is only 6.4MB.
